# Kbd

Kbd — a keyboard key or shortcut.

**Consumer provides:** the key text, one `ds-kbd` per key; join combos with a thin space, not a plus.

- Mono, `bg-100`, `line-strong` border with a 2px bottom edge. Used in search inputs, menus and the shortcuts sheet.
- Use platform-native symbols (⌘ ⇧ ⌥) on macOS and words (Ctrl, Shift) elsewhere.
