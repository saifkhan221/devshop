# Topbar

Topbar — the sticky header across the content area.

**Consumer provides:** breadcrumbs or a title on the left, the global search (`Input` with a search icon and `⌘K` kbd) centred, and the actions cluster (icon buttons + avatar) on the right.

- Height is `space-16` (64px), `bg-100`, `line` bottom border, `z-sticky`.
- Never put the page's primary action here; it belongs in the page header.
