# Toggle

Toggle — an on/off switch that takes effect immediately.

**Consumer provides:** a hidden `<input type="checkbox">` inside the label, then `ds-toggle-track`, then the label text. Label on the right, always.

- On = `peach` track with an `on-peach` thumb; off = `bg-300` with a `line-strong` outline so it is visible on any surface.
- Use a toggle only when flipping it saves instantly. If it needs a Save button, use `Checkbox`.
