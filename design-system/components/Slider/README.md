# Slider

Slider — a native range input with a peach filled track.

**Consumer provides:** `min`, `max`, `step`, a `ds-label` with the current value shown in `ds-num`, and `DevShop.syncSlider(input)` on `input` so the WebKit track fill follows the thumb.

- Use for continuous values a person tunes by feel (opacity, zoom, quality). Exact numbers get an `Input` beside the slider.
