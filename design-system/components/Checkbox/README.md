# Checkbox

Checkbox and Radio — selection inside forms and lists.

**Consumer provides:** the hidden native input, then `ds-check-box` (with the check SVG) or `ds-radio-dot`, then the label. Group radios with a `fieldset` and a `ds-label` legend.

- Checked = `peach` fill, `on-peach` mark. Indeterminate uses the same fill with a dash.
- In a table, the header checkbox selects all; selected rows get `is-selected` (`peach-soft`).
