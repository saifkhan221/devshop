# Tooltip

Tooltip — a short label on hover or focus.

**Consumer provides:** the text (≤ 8 words, or a value in `ds-num`), attached to a `ds-tooltip-anchor` wrapper, shown on `:hover` and `:focus-within`.

- `ink` fill with `ink-inverse` text, `radius-xs`, 8px above the anchor with a 5px arrow. Same styling for chart tooltips.
- Tooltips never contain actions or links.
