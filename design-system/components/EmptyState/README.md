# EmptyState

EmptyState — what a blank list or search result says.

**Consumer provides:** a 24px icon in the `ds-empty-art` well, a `ds-empty-title` naming the space, one sentence of `ds-empty-body` saying what goes here, and exactly one action (`ds-btn-primary`), or none for a search miss.

- Centred, `space-12` vertical padding, body ≤ 36ch.
- Search misses say what was searched and offer to clear: "No tools match 'yaml'. Clear search."
- No illustrations, no emoji.
