# Tabs

Tabs — switch between views of the same object.

**Consumer provides:** buttons with `role="tab"` and `aria-selected`, optionally a count `ds-badge`; `DevShop.bindTabs(el)` handles the switch.

- Underline tabs (`ds-tabs`) sit directly under a page or card header. The active indicator is a 2px `peach` bar.
- `ds-tabs-pill` for filter chips inside a card (All / Mine / Shared).
- Never more than six tabs; never tabs inside tabs.
